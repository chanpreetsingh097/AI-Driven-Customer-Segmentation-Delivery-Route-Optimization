# AI-Driven Customer Segmentation & Reinforcement Learning

## Overview

This project demonstrates **Unsupervised Learning** and **Reinforcement Learning** through practical business applications.

### Customer Segmentation

**K-Means Clustering** is used to group online retail customers based on **monthly spending and app visits**, helping identify similar customer behaviour.

### Reinforcement Learning

The project introduces **Agent, Action, and Reward** concepts to demonstrate how AI can learn through reward-based decision-making.

## Technologies

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Google Colab

## Business Applications

The project can support **customer analytics, targeted marketing, personalization, and intelligent decision-making** across e-commerce, retail, fintech, and digital businesses.

## Key Learning

The practical demonstrates how Machine Learning can convert customer data into meaningful business insights and introduce intelligent decision-making using reinforcement learning concepts.
